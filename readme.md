🌍 Satellite Image Classification using CHDM

 📌 Project Description
This project uses a Hybrid CNN + Diffusion-inspired Deep Learning Model (CHDM) to classify satellite images into land cover categories.

 🚀 Features
- CNN feature extraction
- Diffusion-inspired refinement layer
- 10-class satellite classification (EuroSAT dataset)
- Training, evaluation, and prediction pipeline
- Streamlit web app

 📊 Classes
- Forest, River, Residential, Industrial, Highway, etc.

 🧠 Model Architecture
CNN Encoder → Diffusion Refiner → Classifier
